# AI Cover Maker

> The design should be portable, inspectable, editable, and understandable by both humans and AI.

一个跑在浏览器里的封面工具。零后端，不用注册，东西全在你自己机器上。

干活的路子是这样：

```
想法 / 参考图 → AI → 一段 JSON → 这个工具 → 你手动微调 → 导出 PNG
```

中间那层 JSON 是重点。设计不再是 PSD 那样一坨打不开的二进制工程文件，而是一份人能读、AI 能改、程序能渲染的纯文本。换配色、改文案、切比例，动的都是这份 JSON。

## 先跑起来

```bash
npm install
npm run dev
```

默认开在 http://localhost:3000，端口以 Vite 实际输出为准。打包用 `npm run build`，会先过一遍类型检查再构建。

技术栈：Vue 3 + TypeScript + Vite。

## 这东西主要解决什么事

给长期用同一套风格出封面的人用的——B 站视频封面、YouTube 头图、公众号/小红书配图这类。

版式、配色、装饰先固化成一个模板，之后每期只改文案、换张图、点一下预设换色，再按平台切个比例导出。不用每次开设计软件重新排版。

模板库、配色 token、比例适配、「另存为我的模板」这些功能，都是被这个用法倒逼出来的。

## Design JSON

一个封面 = 一块画布 + 若干元素。

```
Canvas
├── Text
├── Image
├── Shape
└── ...
```

每个元素自己记着位置、尺寸、旋转、层级，以及类型专属的属性。图片靠 `src` 引路径，不往 JSON 里塞 base64——这样换图不用动版式。

下面这份可以直接粘进工具的「导入」框，能过结构校验：

```json
{
  "id": "summer-sale-demo",
  "name": "夏日促销示例",
  "category": "sale",
  "canvas": {
    "defaultWidth": 1080,
    "defaultHeight": 1350
  },
  "elements": [
    {
      "id": "photo",
      "type": "image",
      "src": "assets/product.jpg",
      "x": 100,
      "y": 200,
      "width": 880,
      "height": 600
    },
    {
      "id": "title",
      "type": "text",
      "content": "SUMMER SALE",
      "x": 120,
      "y": 100,
      "width": 840,
      "height": 120,
      "fontSize": 80,
      "fontWeight": 700
    }
  ]
}
```

导入闸门会逐条查这几个字段：顶层 `id` / `name` / `category` 必填；画布尺寸写在 `canvas.defaultWidth` / `defaultHeight`（不是 `width` / `height`）；每个元素也要有唯一 `id`。缺一个就挡回来，而且一次性把问题全列给你，不挤牙膏。

`category` 得取内置那 34 个分类 id 之一，比如 `sale` / `game` / `music`。

完整模板比上面这份还能再多几个字段：

- `tokens`：配色和字体变量，元素里用 `{ "$t": "colors.primary" }` 引用
- `presets`：一键换色方案
- `animation`：元素动画
- `$random`：随机描述符（实验性，少数模板在用，同一模板每期自动微调版式）
- `anchor`：九宫格定位基准。缺省和显式写 `'top-left'` 完全同义，内置模板一般不写，主要切比例时用得上

**编组（`group`）**：一个装饰如果被拆成了好几个元素（条码条纹、齿孔、刻度、点阵、网格线），给它们打同一个 `group`，就能整组选中、拖动、删除。`group` 只用于纯装饰（`shape` / `image` 且不可编辑）。没写也行——运行时按 id 前缀兜底，同一前缀的不可编辑装饰元素满 3 个自动成组。

Schema 还在随着开发继续补。

## 功能

**模板和批量出图**

- 内置 300+ 模板、34 种风格分类（视频封面 / 游戏 / 音乐 / ACG / 科技 / 运动 / 旅行 / 国风……），分类视图 + 过滤 + 全文搜索，常用的 ★ 收藏置顶，不想要的也能隐藏
- 配图全在本地（`public/images/photo`），断网照样编、照样导
- 配色 token + 预设方案：版式不动，一键整套换色；自己存的「我的变体」记在本机，刷新不丢
- 字体 token；$random 随机描述符（实验性）
- 元素动画，20+ 种关键帧，预览/暂停可控
- 比例切换：1:1 / 4:3 / 3:4 / 4:5 / 16:9 / 9:16 / 自定义，配三种适配算法（同色扩展 / 对等裁切含保边锚点 / 等距缩放）。满幅背景和贴边装饰自动跟铺，越界内容有幽灵预览。另有「🍿 平台尺寸」一键套小红书 / B站 / 抖音 / 公众号的标准像素
- 「另存为我的模板」：把当前画面连同你的改动一起烘焙成本地模板，之后还能换色换字体。编辑过程自动暂存进按模板分格的草稿箱，刷新后能点名恢复
- 批量出图：贴一张表（一行一条封面，Tab 分列），按文案槽顺序自动填词，一次导 N 张 PNG。表格存本机，下次打开接着改。跑完逐行报账——哪行文字撑破了盒子、哪行导出失败、还有几个坑位没换图
- JSON 导入 / 导出（源模板和烘焙版都有）

**编辑器**

- Text / Image / Shape / Overlay 四类元素
- 「📝 文案」页签：把画面里所有文本按阅读顺序摊成一张填词表，Tab / Shift+Tab 在框之间首尾环绕，逐条改完就出图；单条能 ↺ 还原，输入框跟着内容自动变高。右侧面板默认开这一页（点画布元素会自动跳「🧩 元素」）
- 「🖼 换成图片」：模板里「这里放主子的脸」这类图片坑位提示语，一键换成同形状同尺寸的图片框，再上传或从素材库灌图，Ctrl+Z 退回文字
- 移动、缩放、旋转、多选、对齐、图层顺序、锁定
- 选中就展开 📐 Transform；顶上「微调:」步长（1/2/5/10px）加四向按钮，不用记方向键
- 形状属性卡：线条 / 色块 / 圆形能直接改填充色、粗细、圆角、不透明度；1~4px 的细线会自动扩大点选热区
- Duplicate / Copy / Paste、Undo / Redo、快捷键总览（+/-/0/1 缩放、/ 直达搜索、Esc 逐级退出）
- 导出聪明化：改过文案后，导出文件名自动取改过的标题前 10 字（跟批量同口径）；导出前有体检，会点名「还没换图的坑位 / 溢出盒子的文字」，只提醒不拦
- 图片替换（本地上传 + 内置 SVG 编辑器）、标尺和参考线、网格（都不进导出）
- 画布缩放和导出倍率（1x/2x/3x）是分开的。缩放只影响你看到的，不影响实际设计尺寸和导出尺寸
- 全屏专注模式（. 键切换）

**图片和模板的备份**

- 开发模式下上传的本地图，dev 服务器会直接落盘进 `public/images/<分类>/`；外链图也能「存入」转成本地
- 「我的模板」能单张或整库导出 JSON，也能从文件导入恢复，清了浏览器数据照样找得回

## AI 怎么用

工具里不内置任何 AI 接口，也不需要 API key。所有 AI 活走剪贴板：工具把该说的话写好 → 你粘给任意一个 AI（Claude / ChatGPT / Gemini / 本地模型，谁顺手用谁）→ 把返回的 JSON 粘回导入框。模型随便换，工具不绑任何服务。

目前跑通的几段：

**复刻同款**：右栏「🤖 AI 复刻同款」把当前模板打包成一段带硬性约束的提示词（改什么、不许动什么，写死在里面），一键复制；AI 返回的新 JSON 直接进导入闸门。模板里的大图（内联 SVG / data URI）会先折成 `{{IMG:元素id}}` 占位符再发出去，回来时按占位符回灌原图——不然几十 KB 的 base64 扔给模型，大概率抄坏。

**场景生成 / 批量变体**：描述一个主题，让 AI 按契约产出整套模板，或者一次产出一批 JSON 数组、整批存进「我的模板」。

**导入闸门**：所有进来的 JSON 先过结构校验，问题一次性列全再放行，不会画一半崩掉。提示词和校验共用同一份契约定义，两边不会漂移。

还没打磨好的是 `图片 → Design JSON` 这一段：把一张喜欢的封面截图丢给视觉模型、让它吐符合 Schema 的 JSON，今天就能试，但还原度看模型。`image-to-json/skills/image-to-JSON-skills.md` 那份字段规范可以整份复制进对话。

## 一些没打算做的

账号、云端同步、协作、内置 AI 接口——都跟「零后端、全本地、JSON 即设计」这个前提冲突，短期内不会出现在这个仓库里。

数据想带走？「我的模板」支持整库导出成一个 JSON 文件，扔你自己网盘里就是备份。
