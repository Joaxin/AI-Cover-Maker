# backups/user-templates — 「我的模板」的仓库级备份

这个文件夹装 **App 内「⭐ 我的模板 → 全部导出」** 得到的 JSON，
校验后由 git 版本化管理。用户自建模板平时只存在浏览器 localStorage 里，
清浏览器数据 / 换机器即全丢；这里就是那份"清空了也能捞回来"的底稿。

## 收入一份备份

1. App 左侧「⭐ 我的模板」右上角点 **全部导出**，得到 `我的模板-备份-N个.json`
2. 终端跑（会校验 JSON 合法性、内容去重，通过才落盘）：

   ```
   npm run 收模板备份 -- "下载文件夹/我的模板-备份-N个.json"
   ```

3. `git add backups/ && git commit -m "备份：我的模板 N 个"`

建议每次大改自建模板后跑一次；内容与已有备份一致时脚本会自动跳过，不会刷 commit。

## 恢复

App 左侧「⭐ 我的模板」右上角点 **导入**，选本文件夹里任意一份 JSON 即可
（单对象或数组都认；超出数量上限的部分会被忽略并提示）。

## 说明

- 这里的数据是个人模板内容，仓库只作本地/OneDrive 备份用，不对外发布。
- 文件名格式：`user-templates-<时间戳>-<N>个.json`。
